# DRONE_S500
# S500 Quadcopter — Pixhawk 2.4.8

## Project Overview

This project focuses on the assembly, configuration, and validation of an S500 quadcopter using a Pixhawk 2.4.8 flight controller and ArduPilot.

## Hardware Components

- S500 quadcopter frame
- Pixhawk 2.4.8 flight controller
- FlySky FS-i6X transmitter
- FlySky FS-iA6B receiver
- 4 × 1000KV brushless motors
- 4 × 30A ESCs
- 3S LiPo battery — 11.1V, 3300mAh, 35C

## Project Objectives

- Assemble and inspect the quadcopter.
- Configure the flight controller using Mission Planner.
- Calibrate the available sensors and radio controls.
- Verify motor operation and flight stability.
- Document safety constraints and validation procedures.

## Current Limitations

The current hardware inventory does not establish autonomous obstacle detection or avoidance capabilities. These functions are outside the validated scope of this document.

## Safety

All configuration and motor tests must follow appropriate safety procedures. Propellers must be removed during ground configuration and motor testing.
